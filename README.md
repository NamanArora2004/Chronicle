Chronicle

Chronicle is an Android application that preserves and promotes cultural heritage by combining community interaction, blogs, 3D monuments.
 The project integrates modern Android development practices with a focus on scalability and user experience.

Features

1) Community: Users can share posts and interact with each other. A marketplace-style section to promote local Indian products.

2) Blogs: A section to read and publish articles about culture and heritage.

3) Chatbot: An interactive assistant that provides guidance and quick answers.

4) 3D Monuments: Integration of 3D models to showcase monuments in an immersive way.
